# Интерфейс и изображения

Интерфейс Лавки создан заново: собственные Django-шаблоны, CSS и JavaScript, системные шрифты. Предоставленный Skillbox пакет diploma-frontend, его шаблоны, статика и шрифты в этот репозиторий не перенесены. Интерфейс не заявляется единолично написанным без помощи инструментов: использовалась помощь Codex.

Четыре вымышленных изображения товаров сгенерированы встроенным image_gen. Файл storefront_ui/static/lavka-products.png используется через CSS-позиционирование четырёх ячеек. Изображения иллюстративные; реальных товаров и продаж нет.

Промпт: ecommerce product photography contact sheet, 2 columns by 2 rows, warm ivory studio background; sage green desk lamp, oak desk organizer, bent oak laptop stand, cream ceramic mug; soft shadows; no text, logos or branded objects.
